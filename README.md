Бұл — "Фильмдер рейтингі базасы" деген шағын бағдарламаның интерактивті консоль жүйесі.
Пайдаланушы меню арқылы фильм қосады, рейтингін көреді, іздейді, өшіреді, статистика қарайды — яғни нақты мини-база.

1.1 — Айнымалылар, input, арифметика, логика
Программа атауы ("Фильмдер рейтингі") айнымалыда сақталады.
Пайдаланушыдан фильм атауын, жылын, рейтингін сұрайды.
Рейтингті енгізгеннен кейін 0 мен 10 аралығында ма — логикалық шартпен тексереді.
Жалпы орташа рейтингті арифметикалық формуламен есептейді.

1.2 — Тізім (list), жиын (set), кортеж (tuple)
Жанрлар "drama, comedy" сияқты енгізілсе — олар тізімге айналады.
Барлық жанрларды жинатып, қайталауларды set арқылы тазартады.
Программа версиясы tuple (кортеж) түрінде сақталған, себебі өзгермейтін мәлімет.

1.3 — Мәтіндік әдістер және шарт
Пайдаланушы іздеген киноны табу үшін кіру мәтіні → кіші әріпке айналады (.lower).
Егер атауда іздеген сөз бар болса — шарт бойынша табылды деп шығарады.
.split(), .replace() сияқты жазу стилін дұрыстау әдістері қолданылған.

1.4 — dict, for циклі, while меню
Негізгі деректер dict түрінде сақталады: "фильм атауы → жылы, рейтингі, жанрлары".
"Барлық фильмдерді көрсету" дегенде, for циклімен әр фильм ретімен шығарылады.
Программа өзі while циклінде шексіз меню болып жұмыс істейді, "9. Шығу" дегенде ғана тоқтайды.
